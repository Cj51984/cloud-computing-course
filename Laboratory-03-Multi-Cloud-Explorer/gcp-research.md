## Brief Overview

Google Cloud Platform (GCP), also called Google Cloud, is a public cloud platform operated by Google. It provides infrastructure and managed services for computing, storage, networking, databases, artificial intelligence, machine learning, analytics, and application development.

## Global Infrastructure

Google Cloud organizes its infrastructure into regions and zones. Resources can be deployed in specific geographic locations depending on requirements such as latency, availability, and data residency.

Google Cloud also operates a global network designed to provide reliable connectivity between users and cloud resources.

## Cloud Management Console

The Google Cloud Console is a web-based graphical interface used to manage Google Cloud projects and resources. Users can create and manage virtual machines, storage, networks, databases, Kubernetes clusters, and other services through the console.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that can run applications and operating systems in Google Cloud.

### 2. Cloud Storage

Cloud Storage provides object storage for storing and retrieving data.

### 3. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service used to deploy and manage containerized applications.

### 4. Cloud SQL

Cloud SQL is a managed relational database service that supports common SQL database engines.

## Three Advantages

1. **Artificial Intelligence and Machine Learning** – Google Cloud provides strong technologies and services for AI and ML workloads.
2. **Kubernetes Expertise** – Google Cloud provides Google Kubernetes Engine for managed Kubernetes deployments.
3. **Global Network** – Google operates a large global network that supports connectivity between cloud resources and users.

## Typical Enterprise Use Cases

Google Cloud can be used for:

- Artificial intelligence applications
- Machine learning projects
- Data analytics
- Kubernetes and containerized applications
- Web applications
- Database systems
- Big data processing
- Global applications
