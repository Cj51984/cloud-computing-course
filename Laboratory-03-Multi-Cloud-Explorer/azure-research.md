## Brief Overview

Microsoft Azure is a public cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, networking, databases, analytics, artificial intelligence, application development, and enterprise workloads.

## Global Infrastructure

Azure provides a global infrastructure organized into regions and geographies. Azure regions contain physical datacenters and networking infrastructure. Many Azure regions also support Availability Zones that provide additional resiliency and fault isolation.

Azure geographies can also help organizations meet data residency and compliance requirements.

## Cloud Management Console

The Azure Portal is a web-based management console used to create, configure, monitor, and manage Azure resources. Users can manage virtual machines, databases, storage, applications, networks, subscriptions, and other services through the portal.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable computing resources for running Windows and Linux operating systems in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage provides scalable object storage for large amounts of unstructured data.

### 3. Azure Virtual Network

Azure Virtual Network provides networking capabilities that allow Azure resources to communicate securely.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users, applications, and resources.

## Three Advantages

1. **Microsoft Integration** – Azure integrates strongly with Microsoft products and technologies.
2. **Global Availability** – Azure provides cloud infrastructure across many global regions.
3. **Enterprise Features** – Azure provides services designed for enterprise security, identity, networking, databases, and application management.

## Typical Enterprise Use Cases

Microsoft Azure can be used for:

- Windows Server migration
- Microsoft 365-related enterprise environments
- Enterprise application hosting
- Virtual desktop infrastructure
- Database hosting
- Web applications
- Artificial intelligence and analytics
- Hybrid cloud environments
