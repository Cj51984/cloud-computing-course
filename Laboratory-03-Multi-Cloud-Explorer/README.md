## Mission Overview

This laboratory activity explores three major public cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The purpose of this activity is to understand their services, infrastructure, management consoles, advantages, and possible business applications.

## Cloud Platforms Explored

### Amazon Web Services (AWS)

AWS is a major cloud computing platform that provides services for computing, storage, databases, networking, security, artificial intelligence, and other workloads.

### Microsoft Azure

Microsoft Azure is a cloud platform that provides computing, storage, networking, databases, analytics, artificial intelligence, and enterprise services.

### Google Cloud Platform (GCP)

Google Cloud provides cloud infrastructure and managed services for applications, data analytics, artificial intelligence, machine learning, storage, networking, and Kubernetes.
