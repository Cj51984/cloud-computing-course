## Client A – Startup Company

### Recommended Platform: AWS

AWS is a suitable choice for a startup because it provides many services that can scale as the company grows. A startup can begin with relatively small resources and increase capacity when application usage increases. AWS also provides services that support application development, databases, storage, and monitoring. This flexibility can help the startup avoid purchasing large amounts of physical infrastructure at the beginning.

### Recommended Services

- Amazon EC2
- Amazon S3
- Amazon RDS

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies and identity systems. The university can migrate selected workloads while continuing to use familiar Microsoft technologies. Azure can also support hybrid cloud environments where some systems remain on-premises.

### Recommended Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure Virtual Network

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud is a strong choice for an AI research company because it provides services and infrastructure designed for artificial intelligence, machine learning, data processing, and high-performance workloads. Google Cloud can provide scalable computing resources for experiments and model development. Its Kubernetes services can also support containerized AI applications. The platform is therefore suitable for research environments that require flexible and powerful computing.

### Recommended Services

- Compute Engine
- Google Kubernetes Engine
- Vertex AI

---

## Client D – Global E-Commerce Company

### Recommended Platform: Amazon Web Services

AWS is a strong choice for a global e-commerce company because it provides global infrastructure and services for scalable applications. The company can distribute workloads across regions and Availability Zones to improve availability. AWS services can also automatically adjust resources based on application demand. This is useful for an online shopping platform that experiences changing traffic levels.

### Recommended Services

- Amazon EC2
- Elastic Load Balancing
- Amazon RDS

| AI / Machine Learning | GCP | Strong AI and machine learning capabilities |
