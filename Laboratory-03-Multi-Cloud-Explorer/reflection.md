# Mission 3 Reflection

**Name:** Christopher John Gamboa
**Course:** CCM101 – Cloud Computing

The cloud platform that impressed me the most is Amazon Web Services (AWS) because of its wide range of services and flexible infrastructure. During this activity, I learned that AWS can support many different workloads, from simple applications and storage to enterprise systems and large-scale online platforms. However, I also learned that Azure and Google Cloud have important strengths that can make them better choices for specific situations.

AWS, Microsoft Azure, and Google Cloud have many similarities. All three provide virtual machines, object storage, databases, networking, identity management, monitoring, and other cloud services. They also provide global infrastructure that allows organizations to deploy applications closer to their users. Although their services have different names and features, they solve many of the same basic cloud computing requirements.

Business requirements are very important when selecting a cloud platform. An organization should consider its budget, existing technology, application requirements, location of users, security needs, scalability, and technical skills. For example, a company that depends heavily on Microsoft technologies may benefit more from Azure, while an organization focused on AI and Kubernetes may prefer Google Cloud.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The correct decision depends on how well the provider's services solve the client's specific problem. I also learned that comparing services across providers makes technical decision-making easier.

My GitHub Cloud Computing Portfolio has improved because it now contains organized research, comparison tables, recommendations, screenshots, and documentation. This activity helped me practice technical research and Markdown documentation while developing a better understanding of real-world cloud platform selection.
