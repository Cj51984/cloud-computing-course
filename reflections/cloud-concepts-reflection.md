# Cloud Computing Concepts Reflection

At first, I thought cloud computing was mainly about storing files online. After learning more about it, I realized that I already use different cloud services almost every day. These services make it easier for me to access files, communicate with other people, and create school projects without keeping everything on only one device.

One service I regularly use is **Google Drive**. I use it to store documents, presentations, and other school files. I classify Google Drive as **Software as a Service (SaaS)** because I can use its features without managing the servers or software behind it. It uses a **Public Cloud** deployment model because the service is available to many users through the internet.

Another service I use is **Facebook Messenger**. I use it to communicate with classmates, friends, and family. Messenger can be considered **SaaS** because users simply access its messaging features while the company manages the application and infrastructure. It uses a **Public Cloud** model because it is available to a large number of users online.

The third service I often use is **Canva**. I use it when creating presentations, posters, and other school requirements. Canva is also **SaaS** because its tools are provided through an online application. It uses a **Public Cloud** because users can access the service through the internet.

I am still becoming familiar with **Git and GitHub**, but I have learned that version control is important because it keeps track of changes made to a project. GitHub can help team members work on the same project, review changes, and return to an older version when something goes wrong. I think learning GitHub will be useful for my future projects because it can help me keep my work organized and make collaboration easier.
